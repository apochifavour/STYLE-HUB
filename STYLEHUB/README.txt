STYLEHUB updated files

Copy index.html, style.css and script.js into your existing STYLEHUB folder, replacing the old versions.
IMPORTANT: Keep your existing images/ankara-market.jpg inside the images folder. This ZIP does not contain that image file.
Then run from the STYLEHUB folder: python3 -m http.server 8000
Open http://127.0.0.1:8000/ and refresh with Ctrl+Shift+R.
Checkout is a frontend demo only.
